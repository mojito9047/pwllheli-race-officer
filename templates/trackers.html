Tracker types — what model an IMEI belongs to

The first 8 digits of an IMEI are its type code: every unit of the same model shares it. Traccar reports the protocol, which is coarser — an asset tracker and a router can both be “Teltonika”.

{# A type code belongs to whoever certified the radio, and a tracker built around an off-the-shelf cellular module often ships with the module vendor's codes — the ATC700's datasheet names a Quectel EG915U. Naming the protocol stops another maker's tracker on the same module being labelled as this one. #}

Set protocol when a code might be shared: it is allocated to whoever certified the radio, so two makers using the same cellular module can issue IMEIs starting the same way. A tracker speaking anything else is then not matched, and falls back to its protocol.
